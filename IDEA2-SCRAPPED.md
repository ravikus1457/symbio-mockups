# Idea 2 (mockup subscription) — SCRAPPED 2026-08-13, by Ravi

Killed the same day the launch page was built, on the strength of an independent commercial
+ legal review (`IDEA2-SCRAPPED-review-and-legal-findings.md`, Codex seat at ultra effort).

**Why, in order of weight:**
1. **Legal/reputation exposure was the launch blocker, not conversion.** 222 mockups of REAL
   named businesses were public, written in the business's own official voice, with invented
   hours/services/prices, false-looking "© Business" notices, and **209 pages carrying live
   `tel:` links**. Cited exposure: GitHub trademark policy, 15 U.S.C. §1125(a) false
   association, unlicensed embedded images, CA Civ. Code §3344 on person-named pages.
2. **The product did not match the pitch.** The proof sample showed a fixed template with
   unverified copy while the page promised "tailored, client-ready". Reviewer's estimate:
   **<1% conversion**, plausibly zero from the first 100 visitors.
3. The fix was a rebuild (fictional demo set + a genuinely tailored generator), not an edit.

**What was done rather than deleted:** every one of the 223 pages got `noindex,nofollow,
noarchive`, a persistent "concept design / not affiliated / contact details illustrative"
banner, `tel:`/`mailto:` links neutered (209 → 0), forms disabled, and the false copyright
notices stripped. The sales page is removed. The mockups themselves remain in git history.

**Still open for Ravi (a destructive step, so it was not taken):** whether to unpublish the
222 real-business pages entirely (delete, or make the repo private). Containment reduces
discoverability and confusion; it does not cure unlicensed assets or absent permission.
The `no_site_outreach` lane historically linked to these pages — it has been sending
nothing (eligible pool 0 for 4+ days), so removal would break no active outreach.
